# factorDFA — детерминированный факторный анализ в R

Пакет для студентов-экономистов: считает влияние факторов на результативный
показатель пятью классическими методами ДФА, показывает промежуточные расчёты
и формулы, проверяет баланс и строит каскадную диаграмму.

| Метод | Функция | Для каких моделей |
|---|---|---|
| Цепные подстановки | `chain_substitution()` | любые |
| Абсолютные разницы | `abs_diff()` | `a*b*c`, `a+b-c`, `a*(b-c)` |
| Относительные разницы | `rel_diff()` | только `a*b*c` |
| Индексный | `index_method()` | `a*b`, `a/b`, `a*b/c`, в т.ч. по нескольким товарам |
| Интегральный | `integral_method()` | любые дифференцируемые (`a*b`, `a/b`, смешанные) |

Единая функция `dfa(..., method = "chain" | "abs" | "rel" | "index" | "integral")`
и `dfa_compare()` — все подходящие методы в одной таблице.

## Установка

```r
install.packages("remotes")
remotes::install_github("astrageek/factorDFA")
library(factorDFA)
```

## Быстрый старт

Выручка `V` = численность `N` × выработка `W`:

```r
res <- chain_substitution(V ~ N * W,
                          base   = c(N = 100, W = 10),
                          actual = c(N = 120, W = 12))
res
```

## Как задавать модель

- формулой: `V ~ N * W`
- строкой: `"V = N * W"` (удобно, если названия факторов на русском: `"ВП = ЧР * ГВ"`)
- без левой части показатель называется `y`: `~ a * b * c`

Порядок подстановки — по порядку факторов в модели или явно:
`order = c("N", "W")`. Обычно сначала количественные факторы, затем качественные.

## Форматы данных

```r
# 1. Два именованных вектора (или списка)
dfa(V ~ N * W, base = c(N = 100, W = 10), actual = c(N = 120, W = 12))

# 2. Одна таблица: фактор / план / факт (подходят и английские base / actual)
tab <- data.frame(Фактор = c("N", "W"), План = c(100, 10), Факт = c(120, 12),
                  check.names = FALSE)
dfa(V ~ N * W, tab)

# 3. Таблица из двух строк: базисный и отчётный период
periods <- data.frame(год = c(2024, 2025), N = c(100, 120), W = c(10, 12))
dfa(V ~ N * W, periods)

# 4. Несколько объектов (товары, цеха): показатель суммируется
dfa(R ~ q * p,
    base   = data.frame(q = c(100, 50), p = c(20, 40)),
    actual = data.frame(q = c(110, 45), p = c(22, 44)),
    method = "index")

# Данные из Excel
tab <- readxl::read_excel("data.xlsx")
dfa(V ~ N * W, tab)
```

## Примеры по методам

```r
# Прибыль = объём × (цена − себестоимость) — абсолютные разницы
abs_diff("P = V * (price - cost)",
         base   = c(V = 1000, price = 50, cost = 35),
         actual = c(V = 1100, price = 52, cost = 38))

# Материальные затраты = объём × норма расхода × цена — относительные разницы
rel_diff(MZ ~ V * UR * CM,
         base   = c(V = 2000, UR = 3,   CM = 40),
         actual = c(V = 2200, UR = 2.8, CM = 45))

# Выработка = выручка / численность — интегральный метод
integral_method(W ~ V / N,
                base   = c(V = 1000, N = 40),
                actual = c(V = 1500, N = 50))

# Все методы сразу
dfa_compare(W ~ V / N, base = c(V = 1000, N = 40), actual = c(V = 1500, N = 50))
```

## Коротко о методах

- **Цепные подстановки.** Базисные значения факторов по очереди заменяются
  фактическими; влияние фактора — разность соседних условных показателей.
  Результат зависит от порядка подстановки.
- **Абсолютные разницы.** Упрощённая запись цепных подстановок:
  `Δy(a) = Δa × b0 × c0`, `Δy(b) = a1 × Δb × c0`, `Δy(c) = a1 × b1 × Δc`.
- **Относительные разницы.** Через процентные приросты:
  `Δy(a) = y0 × Δ%a / 100`, `Δy(b) = (y0 + Δy(a)) × Δ%b / 100`, …
- **Индексный.** Факторные индексы `I(a) = Σa1b0 / Σa0b0`, `I(b) = Σa1b1 / Σa1b0`;
  их произведение равно общему индексу.
- **Интегральный.** Неразложимый остаток делится между факторами, результат не
  зависит от порядка: для `y = a × b` —
  `Δy(a) = Δa × b0 + ½ΔaΔb`; для `y = a / b` — `Δy(a) = Δa / Δb × ln(b1 / b0)`.

Справка по любой функции: `?dfa`, `?chain_substitution`, `?integral_method`.
